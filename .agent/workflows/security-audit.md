// turbo-all

1. **Step 1: Define scope and threat model**
   - Goal: Identify assets, trust boundaries, and attack paths.
   - Action: Use `@ethical-hacking-methodology`, `@threat-modeling-expert`, and `@attack-tree-construction`.

2. **Step 2: Review auth and access control**
   - Goal: Detect account takeover and authorization flaws.
   - Action: Use `@broken-authentication`, `@auth-implementation-patterns`, and `@idor-testing`.

3. **Step 3: Assess API and input security**
   - Goal: Uncover high-impact API and injection vulnerabilities.
   - Action: Use `@api-security-best-practices`, `@api-fuzzing-bug-bounty`, and `@top-web-vulnerabilities`.

4. **Step 4: Harden and verify**
   - Goal: Convert findings into fixes and verify evidence of mitigation.
   - Action: Use `@security-auditor`, `@sast-configuration`, and `@verification-before-completion`.
