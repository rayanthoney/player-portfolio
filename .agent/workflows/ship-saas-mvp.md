// turbo-all

1. **Step 1: Plan the scope**
   - Goal: Define MVP boundaries and acceptance criteria.
   - Action: Use `@brainstorming`, `@concise-planning`, and `@writing-plans`.
   - Result: A `task_plan.md` in your project root.

2. **Step 2: Build backend and API**
   - Goal: Implement core entities, APIs, and auth baseline.
   - Action: Use `@backend-dev-guidelines`, `@api-patterns`, and `@database-design`.

3. **Step 3: Build frontend**
   - Goal: Ship core user flow with clear UX states.
   - Action: Use `@frontend-dev-guidelines`, `@react-patterns`, and `@frontend-design`.

4. **Step 4: Test and validate**
   - Goal: Cover critical user journeys before release.
   - Action: Use `@test-driven-development` and `@browser-automation`.

5. **Step 5: Ship safely**
   - Goal: Release with observability and rollback plan.
   - Action: Use `@deployment-procedures` and `@observability-engineer`.
